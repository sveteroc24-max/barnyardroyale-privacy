Удаление данных — Barnyard Royale

Дата последнего обновления: 15/09/2026

Игра Barnyard Royale (разработчик: SveteRoc) не использует серверный аккаунт и не хранит данные пользователя на удалённых серверах. Весь игровой прогресс хранится только локально на твоём устройстве.

Как удалить свои данные

Поскольку никакие данные не хранятся на наших серверах, удаление данных выполняется прямо на твоём устройстве одним из двух способов:

  1. Полное удаление приложения. Удали Barnyard Royale обычным способом (долгое нажатие на иконку → Удалить, либо через Настройки → Приложения → Barnyard Royale → Удалить). Все данные приложения удаляются вместе с ним немедленно.
  2. Очистка данных без удаления приложения. Настройки устройства → Приложения → Barnyard Royale → Хранилище → "Очистить данные". Прогресс (монеты, статистика, скины, достижения) будет сброшен, приложение останется установленным.

Какие данные удаляются

При любом из способов выше немедленно удаляются: монеты, статистика матчей, купленные бонусы и скины, разблокированные достижения, выбранный профиль.

Данные, которые мы не храним и не контролируем

Единственные данные, не хранящиеся локально, — это идентификатор рекламы устройства (Advertising ID), который обрабатывается сервисом Google AdMob при показе рекламы с вознаграждением. Мы не имеем доступа к этим данным и не можем удалить их по запросу — это делает сама Google. Инструкции по управлению или сбросу рекламного идентификатора: Настройки рекламы Google.
